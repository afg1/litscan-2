# Python usage

Every example on this page was run against the fixtures in `tests/fixtures/`,
and the outputs shown are real.

## Terms file

A UTF-8 text file with a `term_id<TAB>pattern` line for each term and no header.
`term_id` is an integer, and it is what gets written to `mentions.term_id`.

```text
1	TTTY4B
2	TTTY4C
3	LINC00251
```

!!! note "Not yet documented"
    In production this file is generated by the RNAcentral import pipeline, not
    by this repo.

## Build the scanner

```python
import litscan_2

scanner = litscan_2.build_scanner("sample_terms.tsv")
scanner.n_terms            # 11101  distinct term_ids
scanner.n_patterns         # 11101  automaton patterns
scanner.n_shared_patterns  # 0      patterns mapping to more than one term_id
scanner.terms_sha256       # 'afb34577a785…', also recorded in every manifest
```

A scanner is immutable and can be reused for any number of scans. Build it once
per process, because for the full vocabulary that takes about 50 s.

## Scan shards

```python
counts = litscan_2.scan_shards(scanner, "shards/", "out/")
# (articles_total, articles_scanned, articles_below_threshold, mentions, notices)
# (4, 4, 0, 4, 1)
```

`shards` can be a directory (every file in it, sorted) or a list of paths.
Shards can be `.xml` or `.xml.gz`. Options:

| Argument | Default | Meaning |
|---|---|---|
| `filter_model` | `None` | Classifier used to score each abstract ([below](#filter-by-rna-relevance)). |
| `min_probability` | `None` | Skip articles whose abstract scores below this. Requires `filter_model`. |
| `n_decompress` | ⌈CPUs / 4⌉ | Shards processed at once. Each one in flight holds 1–1.5 GB of text. |
| `progress` | `True` | Show a tqdm bar, updated per shard. |

There's also `litscan_2.scan_shard(scanner, shard_path, output_dir, filter_model=None, min_probability=None)`
for a single shard. It uses rayon's global thread pool.

## Read the results

```python
import polars as pl

mentions = pl.read_parquet("out/mentions/*.parquet")
articles = pl.read_parquet("out/articles/*.parquet")
```

```text
┌─────────┬────────┬────────────┬────────┬─────────────────────────────────┬─────────────────┐
│ term_id ┆ pmcid  ┆ section    ┆ symbol ┆ sentence                        ┆ sentence_offset │
╞═════════╪════════╪════════════╪════════╪═════════════════════════════════╪═════════════════╡
│ 2512    ┆ PMC300 ┆ discussion ┆ MIR21  ┆ Corrosion near MIR21 street.    ┆ 15              │
│ 9786    ┆ PMC100 ┆ title      ┆ HOTAIR ┆ HOTAIR regulates chromatin      ┆ 0               │
│ 9786    ┆ PMC100 ┆ abstract   ┆ HOTAIR ┆ The long non-coding RNA HOTAIR… ┆ 24              │
└─────────┴────────┴────────────┴────────┴─────────────────────────────────┴─────────────────┘
```

`symbol` is the text as it appears in the article. It can differ in case from
the term: `mir21` in the text matches the term `MIR21`. Only process a shard's
outputs once `out/manifest/<shard>.json` exists (see
[Output files](outputs.md#manifest)).

## Filter by RNA relevance

```python
model = litscan_2.get_filter_model("model.safetensors", "model_metadata.json")

# Score only: every article is scanned, and articles get an rna_probability.
litscan_2.scan_shards(scanner, "shards/", "out/", filter_model=model)

# Filter: articles scoring below 0.5 are not scanned at all.
counts = litscan_2.scan_shards(scanner, "shards/", "out-filtered/",
                               filter_model=model, min_probability=0.5)
# (4, 2, 2, 3, 1)  2 of 4 articles fell below the threshold
```

Only the abstract is scored. Articles without an abstract are never skipped,
and their `rna_probability` is null. To score text directly:

```python
r = model.py_classify("The long non-coding RNA HOTAIR regulates chromatin state.")
r.proba      # [0.00378, 0.99622]  [P(not RNA), P(RNA)]
r.label      # 1
r.fold_prob  # per-fold calibrated probabilities, averaged to make proba[1]
```

See [RNA relevance filter](classifier.md) for how the model works.

## Get the surrounding paragraph

Mentions only store the sentence. `extract_paragraphs` goes back over the shards
and finds the full paragraph for each unique `(pmcid, section, sentence)`:

```python
n = litscan_2.extract_paragraphs("out/mentions/", "shards/", "paragraphs.parquet")

paras = pl.read_parquet("paragraphs.parquet")
joined = mentions.join(paras, on=["pmcid", "section", "sentence"], how="left")
```

Pass the same shards you scanned. Articles are repaired and parsed the same way
as during the scan, so the sentences match exactly.

## Scan a single article

`scan_one` scans one JATS `<article>` string in memory, without writing any
files. It's useful for testing terms:

```python
xml = """<article><front><article-meta><title-group>
<article-title>MIR21 and HOTAIR</article-title></title-group></article-meta></front>
<body><sec sec-type="results"><p>We saw MIR21 up-regulated. HOTAIR was not.</p></sec></body></article>"""

for h in litscan_2.scan_one(scanner, xml):
    print(h.term_id, h.section, h.symbol, h.sentence_offset, repr(h.sentence))
```

```text
2512 title MIR21 0 'MIR21 and HOTAIR'
9786 title HOTAIR 10 'MIR21 and HOTAIR'
2512 results MIR21 7 'We saw MIR21 up-regulated. '
9786 results HOTAIR 0 'HOTAIR was not.'
```

`scan_one` doesn't apply the double-UTF-8 repair or the filter model.
